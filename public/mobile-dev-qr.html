Scan this code on the same Wi‑Fi as your laptop.

Wrong network? Pick another address:

  • Run npm run dev:all so the API is available.
  • Open this page on your laptop: http://localhost:5175/mobile-dev-qr.html (do not scan dev-mobile-qr.png from the repo — it can be stale).
  • Phone and PC must be on the same Wi‑Fi (not mobile data).
  • Windows: run npm run dev:firewall once (Admin) if the page never loads on your phone.
  • Override: set DEV_MOBILE_URL=http://your-ip:5175/ in .env and restart dev.
  • Add to home screen / Install app does not work on this HTTP Wi‑Fi URL — browsers require HTTPS. Test install on https://uaetrail.com on your phone, or use an HTTPS tunnel (see docs/DEV_RUN.md).
